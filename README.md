# Danijela Stojanovic – Interior Design

Website (Vite, Vanilla JS).

## Starten

```bash
npm install
npm run dev
```

## Build

```bash
npm run build     # erzeugt den Ordner dist/
npm run preview   # Build lokal ansehen
```

Den Inhalt von `dist/` kann man auf jedes Webhosting hochladen.

## Struktur

- `index.html` – Inhalte der Seite
- `src/style.css` – Design (Farben oben in `:root`)
- `src/main.js` – Menü und Rückruf-Formular (E-Mail-Adresse in `EMAIL`)
- `public/img/` – Bilder (Interior-Fotos von Unsplash, Unsplash-Lizenz)
